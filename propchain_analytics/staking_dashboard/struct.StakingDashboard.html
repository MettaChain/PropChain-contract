pub fn record_stake( &mut self, staker: AccountId, amount: u128, current_block: u32, ) -> Result<u128>

Record a stake of amount tokens for staker at current_block.

  • Rejects zero amounts.
  • Accumulates pending rewards before updating the balance so the staker’s existing stake earns rewards at the old rate first.
  • Returns the staker’s new total balance.
Source

pub fn record_unstake( &mut self, staker: AccountId, amount: u128, current_block: u32, ) -> Result<u128>

Record an unstake of amount tokens for staker at current_block.

  • Rejects zero amounts.
  • Enforces the LOCK_PERIOD_BLOCKS lock-up.
  • Accumulates pending rewards before reducing the balance.
  • Returns the staker’s new total balance.
Source

pub fn claim_rewards(&mut self, staker: AccountId) -> Result<u128>

Claim all pending rewards for staker.

Returns the amount claimed. Callers are responsible for transferring the tokens to the staker.

Source

pub fn distribute_reward(&mut self, amount: u128) -> Result<u128>

Distribute amount tokens as rewards, spread proportionally across all current stakers via the reward_per_token_stored accumulator.

No-op (returns Ok(0)) when there are no stakers.
