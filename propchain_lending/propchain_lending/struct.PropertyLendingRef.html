Check whether a loan (possibly multi-collateral) should be liquidated.

Callable by anyone. Computes the weighted liquidation threshold across all pledged properties and compares it against the current aggregate LTV (total debt / total current collateral value, both in native tokens).

  • current_collateral_values: list of (property_id, current_value) pairs representing the latest market value for each pledged collateral.
